fifteenth → GitHub Gist, for real

Loads the actual fifteenth/gist.js and makes live HTTPS calls to api.github.com. Proves the create → read → merge → read persistence path against a real, git-versioned secret gist. Open the console for the raw request log.

1 · Paste a GitHub token

A token with the gist scope is needed to create / update a gist (reads of a public gist don't need one). Make a fine-grained PAT with Account permissions → Gists → Read and write (no repository access), or a classic PAT with the gist scope. It is stored only in this browser's localStorage and sent only to api.github.com.

2 · Round-trip

Idle. Paste a token, then click “Run round-trip”.
